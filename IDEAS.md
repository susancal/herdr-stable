# Ideas

The ideas below are not built yet. The first group would make each horse show more about its agent, and the later groups add barn activity, larger projects and small fixes.

## Horses that show more about their agent

- Give each horse a name, e.g., "Biscuit" or "Sir Neighs-a-Lot", chosen from its terminal address so the name never changes. Names would make it easier to tell horses apart at the trough without hovering over them.
- Write the agent's git branch on the horse's saddle blanket, in place of the small tag on the stall wall.
- Give a horse muddy legs after it has worked for more than an hour, and wash the mud off when it goes to the trough.

## Barn activity

- Turn on the real-weather windows, and send idle horses into their stalls when it rains. The weather setting sends your IP address to an outside service for a rough location.
- Add a rooster that crows when you start the first agent of the morning.
- Add a grooming station, so that clicking a horse brushes it and marks a finished agent as seen without leaving the barn.
- Add more seasonal decorations, e.g., a Derby day hat in May and a pumpkin carving contest at Halloween.

## Larger projects

- Add a second layout, called a paddock, where all the horses graze in an open field. The paddock would fit more agents than the row of stalls.
- Start a rodeo when two agents work on the same git branch at the same time, so their horses face off. The rodeo would warn you that the two agents might make conflicting changes.

## Small fixes

- Replace the hoof stamp sound for blocked agents, which is generated in code, with a real recording. One option is another part of the clip-clop recording, and another is a stamping recording from Freesound.
- Make the windows always show a daytime sky when night mode is off, to match the barn, which stays bright.
- Save the count of recent finishes that starts an apple party, so a reload does not reset it.
- Remove the line on the ribbon wall that names the agent with the most ribbons, if the board should show only the ribbons.
